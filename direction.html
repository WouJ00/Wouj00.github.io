Data Science en Software Engineering

Data Science is het vakgebied waarin je data verzamelt en vervolgens deze data analyseert. Data Science is nuttig om informatie te krijgen over bepaalde patronen in data, waardoor ook voorspellingen voor de toekomst gedaan kunnen worden. Data Science maakt veel gebruik van machine learning, net zoals generatieve AI tegenwoordig.
Software Engineering is simpel gezegd het ontwerpen/ontwikkelen van software. Programmeren is hierbij heel erg belangrijk. Buiten het ontwerpen of ontwikkelen van software is ook het onderhouden en testen belangrijk voor de ontwikkeling van software. Software is heel nuttig voor allerlei dingen. Er is software voor vermaak, software om dingen bij te houden, software om gevaren tegen te gaan etc.

Mijn Studierichting

Ik ben er vrij van overtuigd dat ik later de software engineering weg wil nemen. Dit is het meeste in lijn met wat ik tot nu toe als hobby heb gedaan en ook de grootste reden dat ik voor deze opleiding koos. Toen er bij de open dag gepraat werd over de splitsing tussen Software Engineering en Data Science, wist ik mijn keuze eigenlijk al.
Het maken en/of modificeren van apps vind ik persoonlijk heel erg leuk. Ik houd van puzzelen en systemen bedenken en bij programmeren kom je vaak indirect puzzels tegen.
Ook heb ik eerder met databases gewerkt bij Informatica op de middelbare school en ik vond dat zelf niet heel erg leuk. Ik vind het nog steeds interessant en ik ben benieuwd hoe het vak Data Science Basics gaat zijn, maar ik denk persoonlijk niet dat ik het leuker ga vinden dan het programmeren.
Data Science heeft natuurlijk ook veel te maken met AI, wat ik op zich wel interessant vind, maar AI is niet iets waar ik me per se in wil specialiseren. Dat kan natuurlijk nog veranderen (after all, ik heb DSB nog niet gehad), maar ik ga er op dit moment niet vanuit.

Waar zie ik mezelf in de toekomst?

Waar ik mezelf in de toekomst zie vind ik een interessante vraag, want ik denk dat het voor een redelijk groot deel aan externe factoren ligt. De ICT ontwikkelt zich heel erg snel, met name kijkend naar AI. Of software engineers nog nodig zijn in een tijdperk waar AI waarschijnlijk heel prominent wordt, is nog maar de vraag. Uiteindelijk zal er nog altijd iemand nodig zijn die de code kan begrijpen en lezen. Ook lijkt het mij nog steeds leuk om code te schrijven puur als hobby, zoals ik nu ook doe.
Wat ik later precies als functie wil doen blijft voor mij nog een vraag. Een vraag waarvan ik niet weet wanneer ik die ga kunnen beantwoorden. Ik wist pas in VWO6 welke opleiding ik wilde doen en het zou me niets verbazen als mijn keuze deze keer weer lang gaat duren.
